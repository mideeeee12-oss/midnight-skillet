**The Midnight Skillet** — a tiny late-night diner game for desktop browsers. Take orders from the board, chop, fry and simmer the ingredients, build each dish on a plate and serve it before the customer's patience runs out. Four recipes, two skillets, one soup pot, one chopping board, three plates and a 150-second shift: coins, tips and combos for fast hands, burnt steak for slow ones. Plain static files, no build step, no network — open `game/index.html` and play with mouse or keyboard.

## Run it

```sh
node serve.ts
```

then open http://localhost:8080 — or hand the entry in with `MAKEFUN_OUTPUT_DIR=out node main.ts`.
